■ 모델 단계
1. 특징: 규칙·구조 특징(alt와 링크 텍스트·인접 문맥의 겹침 등), TF-IDF, PaddleOCR 이미지 속 글자,
   VLM 임베딩(Qwen3.5-9B, InternVL3.5-14B), VLM 예/아니오 속성 질의
2. 가이드라인 판정기
   - Qwen3.8-27B에 가이드라인 전문 + 이미지·alt·문맥·OCR을 주고 7범주 확률을 읽음

3. 스태커: 위 특징 + 판정기 출력 → LightGBM. 학습 2,400 + 공개 109 + 규칙 확정 test 행으로 학습
4. 지도학습 VLM: Qwen3.8-27B LoRA(이미지 + 증거 카드) + 보조 Qwen3.5-9B LoRA, 전체 학습본으로 test 예측
5. 결합: 0.6 x (0.9 x log P스태커 + 0.1 x log P판정기LR) + 0.4 x 평균 log P(LoRA)
6. 할당량: 공개 문서로 도출한 평가셋 분포에 예측 개수를 맞춤

■ 하네스의 핵심 원리: 검수 일치
- 주최 측은 test 600행 전체를 독립 검수했고, 원 라벨과 검수가 갈린 109행만 공개(경계사례)
- 나머지 491행은 원 라벨 = 검수 라벨인 행 → 정답은 두 라벨러가 동의한 라벨
  P(y | x, 일치) ∝ P원라벨러(y | x) x P검수자(y | x)
- 공개 쌍둥이의 검수 라벨을 옮기는 것(H2·H4)은 검수자의 페이지 내 일관성을 이용하는 것
- 원 라벨러가 그 구조에 그 라벨을 줄 수 없으면(학습 구조 사전확률 ≈ 0) 옮기면 안 됨 → H5
- 리더보드 검증: H5로 거부한 3행 모두 실제 불충분형 (0.9304 → 0.9357, 역산 결과 3/3)

■ 검증 하네스: 학습 데이터 시뮬레이션 (koaltq2/harness_val.py, 30회 반복)
- 주의: 이 시뮬레이션은 '무작위로 고른 공개 행의 원 라벨을 페이지 쌍둥이가 공유하는가'를 잴 뿐,
  test에서 실제로 쓰는 '불일치 행의 검수 라벨 전파'를 검증하지는 않음
  (test의 공개 109행은 모두 원 라벨 ≠ 검수 라벨이고, 학습 데이터에는 검수 라벨이 없음)
- OOF 예측은 스태커 결합(LoRA 혼합·할당량 적용 전)의 정직한 fold 밖 예측
- test와 같은 비율(페이지별 18%)의 행을 '공개 행'으로 두고, 나머지 행의 정직한 OOF 예측을
  쌍둥이 규칙으로 보정했을 때 (회당 평균)
  - H2 템플릿 쌍둥이: 54.2행 변경, 정밀도 0.436, 순이득 -6.5행
  - H4 구조 쌍둥이(불충분→적절): 64.9행, 0.475, -2.8행
  - H6 서명 투표(이웃 2건 이상, 100%, 게이트 없음): 33.9행, 0.575, +4.0행
  - H6 서명 투표(이웃 2건 이상, 100%, 확신도 0.9 이하): 23.6행, 0.701, +9.6행 → 학습에서는 동료 설계가 가장 정밀
  - 하네스 순서대로(H2 → H2가 정하지 않은 행에 H4 → 둘 다 손대지 않은 행에 H6) 적용하면:
    H4 43.6행, 0.489, -1.2행 / H6 6.7행, 0.769, +3.6행
- 해석
  - 학습 데이터에는 검수 구분이 없어서, 여기서는 원 라벨러의 페이지 내 일관성만 측정됨
  - test에서 H2·H4가 이득인 이유는 검수 일치 구조 때문
  - 리더보드 근거: R4를 데이터셋 라벨 대신 재판정 라벨로 전파했을 때 0.8379 → 0.86, H4+H5는 9행 결정이 모두 정답

■ Conformal 예측집합 분석 (alpha 0.1, 교차 보정)
- OOF 커버리지 0.897, 평균 집합 크기 1.06 (모델이 대부분 단일 라벨로 확신)

  (실제로 적용한 6행 중 5행 포함)
- 결론

  - 불확실성(확신도·conformal) 게이트로는 못 찾고, 공개 쌍둥이 증거 + 검수 일치 거부로만 교정됨
  - 그래서 H2·H4에는 확신도 게이트를 쓰지 않음

- 최종 하네스는 H0~H5(= 21번, 0.9357). H6는 평가 실험으로만 보고(점수 비슷하지만 소폭 하락)
